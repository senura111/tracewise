Finish the **function** `celsius_to_fahrenheit` so that it takes a temperature in degrees Celsius and **returns** it in degrees Fahrenheit.

The formula is: multiply by 9, divide by 5, then add 32.

The rest of the program is already written: it reads a temperature, calls your function, and prints the answer to 1 decimal place. For example, `100` should print:

```
212.0
```

Your function should **return** the answer, not print it.
