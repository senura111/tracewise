Every line has the same shape; only the multiplier changes, from 1 to 10. Loop over the multipliers.

---

`for (int i = 1; i <= 10; i++)` runs with `i` = 1, 2, … 10. `<<` can print the result of a calculation directly: `cout << n * i;`.

---

Inside the loop: `cout << n << " x " << i << " = " << n * i << endl;`
