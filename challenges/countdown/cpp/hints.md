You need to print a number several times, going down by one each time. That's a job for a loop.

---

A C++ `for` loop has three parts: where to start, when to keep going, and how to change each time. Counting down: `for (int number = n; number >= 1; number--)`.

---

Print `number` inside the loop's braces, and print `"Liftoff!"` after the closing brace, so it only happens once.
