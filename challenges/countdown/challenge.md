---
title: Countdown
difficulty: easy
topics: [loops]
order: 6
---

Your program is given a whole number `n` (0 or more). Count down from `n` to `1`, printing each number on its own line, then print `Liftoff!`.

For example, if `n` is 3, print:

```
3
2
1
Liftoff!
```

If `n` is 0, there's nothing to count, so just print `Liftoff!`.
